# AI 采购助理（AI Procurement Assistant）

> 把采购员从「手动对齐、逐格换算、肉眼找最低价」里解放出来：上传报价单 → 自动解析 / 对齐 / 换算 / 比价标红 / 出建议。
> 本地优先、默认不出本机；规则引擎为主，**LLM 只在长尾兜底**。

作者：**杨智潜**（采购方向实习中，2027 届）｜定位：AI 产品岗作品集 + 采购岗数字化实证

---

## 1. 解决什么问题

采购日常的真实流程：收 3~10 家供应商报价（Excel 格式各异）→ 复制粘贴对齐品类 → 含税/不含税换算 → 逐格找最低价 → 标红汇总 → 写结论。

**痛点**：一份多供应商比价手工 10~30 分钟且易错（错税率、错对齐）；报价单格式不统一（合并表头、供应商名在 sheet 名、二次报价追加列、同品异名）；结论靠经验、无沉淀。

**本工具**：单机网页，覆盖「解析 → 对齐 → 换算 → 标红 → 建议」，并沉淀本地经验库，**越用越快**。

## 2. 核心能力（三个任务模式）

| 模式 | 说明 |
|---|---|
| **两表匹配补缺**（VLOOKUP 类，日常最高频） | 钥匙列精确 → 模糊 → 补充列 → **经验库兜底** → **LLM 语义兜底** → 空白；重复预警/未匹配可人工确认回写；支持**原文件写回 + 自动 ai 副本备份** |
| **仅换算** | 含税↔不含税，多税率、按列独立、列名自动识别税率；合计/公式行自动跳过（保护 SUM 区）；写回原文件 |
| **完整比价** | 多文件/多 Sheet 解析（**规则优先 + LLM 兜底**）→ 组合键对齐成矩阵 → 口径统一（默认不含税）→ **最低价标红（浅色彩虹色卡/自定义）** → 导出 → 规则版采购建议 |

**配套能力**
- **匹配经验库（本地飞轮）**：人工确认沉淀 → 下次兜底命中；**同一左键可覆盖、可删单条、可清空**；不自动入库，不被推测污染
- **LLM 兜底（可选，默认关）**：厂商无关适配器（OpenAI 兼容），**内容缓存 + 成本留痕 + 单次调用上限**；非标解析与语义配对带置信度/理由，结果标来源供复核
- **工程细节**：两行合并表头自动拆分、数据区合并单元格按显示效果填充、公式行保护、色卡可配、崩溃日志 `logs/app.log`、**改代码后启动脚本自动重启**、成本日志 `logs/llm.log`

## 3. 技术架构

```
UI（Streamlit）
  ├─ 两表匹配补缺 / 仅换算 / 完整比价（预览式点选：表头行、列、钥匙列…）
  └─ 侧栏：经验库管理 / LLM 配置与自检 / 运行日志 / 技能注册表
        │
流水线编排（按模式裁剪）
  匹配：钥匙精确 → 模糊 → 补充列 → 经验库兜底 → LLM 语义兜底 → 人工确认 → 回写经验库
  比价：parse（规则 → LLM）→ align（组合键+经验库兜底）→ convert → highlight → advise
        │
core/（每模块挂技能卡，registry 为 V2 意图路由地基）
  matcher  parser_rule  parser_llm  aligner  converter  highlighter
  advisor_rule  experience  llm_client  excel_io  registry
```

## 4. 快速开始

```powershell
# 1) 依赖
py -m pip install -r requirements.txt

# 2) 启动（Windows 双击亦可）
py -m streamlit run app.py
# 或双击：启动采购助理.bat（端口占用会复用；改代码后自动重启）
```

- 侧栏「🤖 LLM」：默认关；启用后非标解析/语义兜底才会调用（本机凭证来自 `~/.local/share/opencode/auth.json` 或环境变量 `LLM_API_KEY`，**不进仓库**）
- 侧栏「🧠 经验库」：查看 / 删除单条 / 清空

## 5. 目录结构

```
ai模型/
├── app.py                # Streamlit 页面（三模式）
├── ui_components.py      # 预览式点选组件
├── 启动采购助理.bat       # 启动脚本（端口复用 / 代码更新自动重启）
├── core/                 # 引擎（模块即技能）
│   ├── matcher.py        #   两表匹配（精确/模糊/补充列/经验库兜底/LLM兜底）
│   ├── parser_rule.py    #   报价单解析（表头探测 + 字段字典）
│   ├── parser_llm.py     #   非标解析（规则优先，LLM 兜底，同接口）
│   ├── aligner.py        #   跨供应商对齐（组合键 + 模糊 + 经验库兜底 + 置信度）
│   ├── converter.py      #   含税↔不含税
│   ├── highlighter.py    #   最低价标红（色卡可配）
│   ├── advisor_rule.py   #   采购建议（最低价/异常低价/缺报价）
│   ├── experience.py     #   匹配经验库（兜底飞轮，可覆盖/删除/清空）
│   ├── llm_client.py     #   LLM 适配器（OpenAI 兼容/缓存/成本日志/上限）
│   ├── excel_io.py       #   读写/备份/写回/合并表头/公式行检测
│   └── registry.py       #   技能注册表
├── data/                 # 见 data/README.md（分类存放；真实数据不进仓库）
├── tests/                # 见下（9 套，离线可跑）
└── logs/                 # 运行/成本日志（不进仓库）
```

## 7. 数据与隐私

- **本地优先**：报价单等业务数据不出本机；LLM 功能**默认关**、开启后仅发送「待兜底的少量数据」
- 仓库内**只含合成样例**（`data/samples/`）；真实基准/原始报价单/日志/产出均被 `.gitignore` 排除
- 凭证只存本机（`auth.json` / 环境变量），**永不入库、不打印**

# data 目录说明（AI 采购助理）

> 纪律：**所有产出都放本项目内、分类存放**；临时文件只放 `%TEMP%\opencode`；每步收尾清残留。

| 目录 | 用途 | 谁负责 | 可否清理 |
|---|---|---|---|
| `raw_quotes/` | **原始逐家报价单**（parser 的输入）。你把供应商发来的原始 파일丢进来，我就能跑真实解析准确率 | 用户投放 | 确认后可按需清理 |
| `ground_truth/` | **人工基准**（只读，别改）：标函分析表（含最低价标色）、事业部匹配结果、汇总表等 | 拷贝自用户桌面 | 不清理（评估依据） |
| `samples/` | **合成样例**（测试用；与真实数据严格分开，报告里也必须分开标注） | 脚本生成 | 可重生成 |
| `outputs/` | **我们生成的产出**（比价结果 xlsx、评估报告等） | 脚本/应用 | 可随时清 |
| `experience.json` | 匹配经验库（人工确认沉淀；随使用增长） | 应用写入 | 可清空（会丢飞轮积累） |

## 当前基准文件

- `匹配表_001_合同进度表.xlsx` ← 来自 `工作台\9.10\001.xlsx`（含写回前快照 Sheet `ai副本合同进度表`，回测用）
- `钥匙表_采购项目汇总.xlsx` ← 来自 `工作台\9.10\采购项目汇总-2026年12月.xlsx`（`事业部匹配结果` = 人工匹配基准）
- `汇总.xlsx` ← 来自桌面 `汇总.xlsx`（多供应商 2 行表头/税率/最小值 格式基准）
- `标函分析表_最低价标色.xlsx` / `标函分析表_秩序服务.xlsx` ← 人工标色成品（标红阶段 ground truth）
- `优选供应商对比分析_含税总价.xlsx` ← 成品矩阵格式基准
- `raw_quotes/物资采购清单_利源通.xls` ← 唯一原始单家清单（parser 真实格式探针）

## 评估纪律（防自嗨）

1. 测试输入与规则设计分离；**不得**用自己按规则造的数据去"证明"规则准
2. 合成数据一律标注 `synthetic`，**不混入真实准确率**
3. 分层报告：格式难度（标准/半标/非标）× 来源（真实/合成），指标含 精确率/召回率/误配/漏配
4. 回测用人工基准：匹配→`事业部匹配结果`；标红→标函分析表标色；换算→100% 硬指标
